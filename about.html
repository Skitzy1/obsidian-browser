Servo engine · Bing search

Privacy

The browser address bar and built-in new-tab page do not request search suggestions. Submitted searches are sent to Microsoft Bing. Websites you visit can receive your IP address, use cookies, and collect data under their own policies.

Bookmarks and appearance settings stay in your local profile. Obsidian adds no telemetry client, account system, history database, or cloud sync. The full engine has not yet been audited for background network traffic.

Security status

This is an experimental browser. Tracker blocking, fingerprinting defenses, signed automatic updates, and a complete security review are still needed. This pinned Servo version does not implement a Windows renderer sandbox. Do not use this preview for sensitive browsing.
